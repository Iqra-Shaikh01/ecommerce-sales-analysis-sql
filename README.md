# E-commerce Sales Analysis Using SQL

## Project Overview
This project focuses on analysing e-commerce sales data using SQL to understand sales performance, customer purchasing behaviour and product trends.

## Tools Used
MySQL.

## Analysis Performed
Used SQL queries to explore and analyse e-commerce data, calculate sales-related metrics and identify useful business insights.

## Key Findings
Analysed sales performance, customer purchases and product-related trends to understand business performance.

## Conclusion
This project demonstrates how SQL can be used to manage, analyse and extract meaningful insights from e-commerce data.
